# Industrial Video Anomaly Detection (IPAD)

**First target project.** Use the public IPAD dataset following provider terms and its available annotation granularity.

Research question: does lightweight VLM reasoning improve interpretable anomaly alerts over an image-only/classification baseline?

Tasks: video manifests, video-safe splits, controlled frame sampling, baseline prompts, reviewed clip labels, LoRA experiments, F1/recall, false-alerts/hour, latency, VRAM, MQTT review queue.

Dataset page: https://ljf1113.github.io/IPAD_VAD/

Do not infer frame-level ground truth from video-level labels without clearly stating the weak-label assumption.
