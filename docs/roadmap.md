# Milestones

- **M0 — Repo baseline**: smoke tests, frame extraction, CSV metrics, MQTT demo (this scaffold).
- **M1 — Data**: inspect IPAD license/access; manifest with real IDs and normal/anomaly labels, split by original video/source.
- **M2 — Baseline**: reproducible small VLM inference, structured output validation, latency + VRAM measurements.
- **M3 — Training**: reviewed instruction labels, configurable LoRA/QLoRA, checkpointing and memory logging.
- **M4 — Edge**: Pi 4 event gateway + retained status dashboard; prevent repeated alerts and enforce human review.
- **M5 — Publication**: dataset citation, model card, license audit, demo video, measured results and failure cases.

**Do not claim a milestone complete until code, tests, and evidence exist.**
